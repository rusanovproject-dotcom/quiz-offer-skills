# Стоп-сигналы и красные линии

## Абстракции, которые нужно проверить

«Потенциал», «оптимизация», «эффективность», «трансформация», «раскройте
возможности», «новый уровень», «комплексный подход», «индивидуальная
программа», «инновационный», «уникальная методика», «профессиональный рост».

Когда абстракция заменяет всё описание результата, критерий конкретики
получает 0. Само наличие слова не обнуляет факты рядом с ним: оценивай смысл,
не совпадение подстроки. Убери пустую формулу или поясни её артефактом,
механизмом, подтверждённым сроком или измеримым изменением.

## Условные примеры замен

Это редакторские **условные примеры**, не сведения о чьём-либо продукте.
Не копируй числовые обещания из примеров. В финале подставляй только
подтверждённые данные; если их нет, оставляй явно отмеченный пробел.

| Абстракция | Конкретизация при наличии основания |
|---|---|
| «Повысить эффективность» | «Готовый отчёт за час вместо пяти» — условный пример |
| «Увеличить доход» | «[Подтверждённое изменение дохода, период и условия]» |
| «Оптимизировать процессы» | «Передать сбор заявок из почты в таблицу» |
| «Раскрыть потенциал» | «Собрать предложение по услуге, которую вы уже умеете оказывать» |
| «Индивидуальный подход» | «Разберём ваш файл и настроим шаблон на ваших данных» |
| «Комплексная программа» | «[Состав программы] + [артефакт на выходе]» |
| «Профессиональный рост» | «[Конкретный навык и способ проверить его освоение]» |

## Красные линии

1. Не обещай результат, который продукт не подтверждает.
2. Не выдумывай сроки, цены, экономию, доход, кейсы, проценты успеха и цитаты.
3. Не создавай ложную срочность, дефицит и скидки. Нет лимита — не добавляй.
4. «Средний результат» допустим только при реальных данных и понятной выборке.
   Слова «примерно», «реалистично» или «в среднем» не легализуют выдумку.
5. Условия гарантии и возврата бери из действующих условий продукта.
6. Не дави на страх без фактического основания и не унижай человека.
7. Не копируй чужой оффер дословно. Применяй структуру к своим фактам.
8. Не публикуй полученные клиентские данные и не используй их в других
   примерах без разрешения. Для демонстрации бери явно условные ситуации.

При нехватке данных дай честный черновик с пометками. Факты о продукте
важнее итогового балла и эмоциональности фразы.
