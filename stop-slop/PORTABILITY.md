# Переносимость и происхождение

Имя `stop-slop` сохранено для совместимого вызова. Отдельный старый
standalone-исходник не найден; эта версия честно перенесена из действующего
anti-slop и его Anti-slop playbook. Сохранены три слоя: язык/структура,
ритм/дополнительные метрики, кураторское усилие/живость.

Метод опирается на anti-ai-slop-writing, русскую редактуру канцелярита
и критерий кураторского усилия Simon Willison. Голос берётся только
из предоставленных материалов. Writing-tools MCP необязателен; без него
доступна ручная проверка. Определение авторства и обход детекторов не входят
в задачу. Офисные пути, память, маршрутизация и личные примеры исключены.
