# Quiz & Offer Skills для Codex и Claude Code

Три скилла для проектирования квизов, персональных результатов и коммерческих предложений. `quiz` включает короткие продающие квизы и глубокие адаптивные квизы как полноценный лендинг. Методология офферов опирается на Хормози, Шварца, Хэлберта и Хопкинса.

## Что внутри

| Скилл | Команда | Что делает |
|-------|---------|-----------|
| **quiz** | `/quiz` / `$quiz` | Проектирует исследовательские, квалификационные, онбординг-, короткие и глубокие продающие квизы: обещание → вопросы и ветки → персональный результат → подходящее следующее действие. |
| **offer** | `/offer` | Конструктор оффера в режиме штурма: приносит 3–5 вариантов на каждом шаге (обещание → формат → механика → бонусы → risk reversal → цена → имя), ты выбираешь, скилл докручивает. На выходе — Core Offer / Tripwire / Lead Magnet. |
| **hormozi** | `/hormozi` | Offer Architect по «$100M Offers»: создание оффера (`--build`), суровый scoring-ревью (`--review`), разведка рынка и voice-of-customer (`--mine`). Value Equation, уникальный механизм, стек бонусов, гарантии. |

`quiz/references/deep-conversion-quiz.md` содержит полную методику глубокого адаптивного квиза: экранную драматургию, персонализацию, доказательства, переход к продукту и аналитику. Пример запроса и критериев результата — в `quiz/evals/evals.json`.

`offer` и `hormozi` несут папки `references/` с разборами фреймворков (offer-playbook, anti-patterns, meanings-engine, offers-framework, message-mining).

## Как установить

Актуальная версия глубокого `quiz` в этом обновлении находится в ветке `codex/publish-deep-quiz`:

```bash
git clone --branch codex/publish-deep-quiz https://github.com/rusanovproject-dotcom/quiz-offer-skills.git
cd quiz-offer-skills
```

Для Codex:

```bash
mkdir -p ~/.agents/skills
cp -R quiz ~/.agents/skills/
```

Для Claude Code:

```bash
# глобально
mkdir -p ~/.claude/skills
cp -R quiz offer hormozi ~/.claude/skills/

# или в текущий проект
mkdir -p .claude/skills
cp -R quiz offer hormozi .claude/skills/
```

Если навык с таким именем уже установлен, сначала сохраните свою версию. Перезапустите приложение или откройте новую сессию, чтобы оно обнаружило навык.

## Как пользоваться

В Claude Code используется `/quiz`, в Codex — `$quiz`. Пример запроса для глубокого квиза:

```text
$quiz Создай полный глубокий продающий квиз для моего продукта:
вопросы, адаптивные ветки, персональные результаты, объяснение продукта,
оффер и аналитика. Не останавливайся только на заголовках.
```

Соседние команды:

```
/quiz          собрать квиз-воронку
/offer         собрать оффер штурмом (Core / Tripwire / Lead Magnet)
/hormozi       создать/проверить оффер или сделать разведку рынка
/hormozi --review   суровый scoring существующего оффера
/hormozi --mine     разведка рынка + язык аватара
```

При запросе полной архитектуры `quiz` собирает весь проход за один такт с явными допущениями. Отдельный запрос на хуки остаётся отдельным запросом. Длительность прохождения и конверсию нужно проверять на прототипе; навык не гарантирует показатели.

## Внешние зависимости

`quiz` проектирует содержание и поведение, а не готовый интерфейс. Он ссылается на `/design-swarm` для дизайна и на `equalizer` для финального ревью оффера. Они не входят в этот репозиторий: используйте свои соответствующие инструменты и явно отмечайте непроведённое ревью. Для чувствительных тем требуется профильная проверка. `quiz` не выдаёт медицинские диагнозы и не выдумывает доказательства, цены, гарантии или скоринг.

## Как они сочетаются

```
/hormozi --mine   →  разведка рынка, язык аудитории, gap-map
        ↓
/offer            →  собрать оффер штурмом на этой фактуре
        ↓
/hormozi --review →  стресс-тест оффера по Value Equation
        ↓
/quiz             →  упаковать в квиз-воронку с этим оффером
```
