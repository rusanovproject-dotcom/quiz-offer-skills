# Quiz & Offer Skills

Девять скиллов для квизов, офферов, лид-магнитов и продающих материалов.
Переносимый комплект: инструкции и справочники лежат здесь, внутренняя инфраструктура
автора и клиентские данные не требуются. Скиллы работают как инструкции для AI-ассистента;
они не являются отдельным приложением или готовым конструктором квизов.

## Состав

| Папка / команда | Для чего |
|---|---|
| [quiz](quiz/SKILL.md) | Короткий или глубокий адаптивный квиз, персональные результаты, оффер и аналитика |
| [offer](offer/SKILL.md) | Штурм основного оффера, трипвайра или лид-магнита |
| [hormozi](hormozi/SKILL.md) | Создание (`--build`), проверка (`--review`), исследование рынка (`--mine`) |
| [equalizer](equalizer/SKILL.md) | Проверка смысла, аргументов и соответствия аудитории |
| [design-swarm](design-swarm/SKILL.md) | Смыслы → структура → интерфейс → визуальные итерации |
| [kp](kp/SKILL.md) | Персональное коммерческое предложение |
| [write-longread](write-longread/SKILL.md) | Продающая статья с механизмом, доказательствами и переходом к продукту |
| [stop-slop](stop-slop/SKILL.md) | Редактура шаблонного AI-языка с сохранением смысла |
| [stephen-king](stephen-king/SKILL.md) | Сокращение и усиление прозы |

Это самостоятельная редакция существующих методов. Что адаптировано и какие возможности
зависят от хоста — в [PORTABILITY.md](PORTABILITY.md).

## Установка

```bash
git clone https://github.com/rusanovproject-dotcom/quiz-offer-skills.git
cd quiz-offer-skills
```

Перед копированием сохраните свои версии скиллов, если такие папки уже существуют.
Копируйте **папку целиком**, включая `reference/` или `references/`.

Для Codex:

```bash
mkdir -p ~/.agents/skills
cp -R quiz offer hormozi equalizer design-swarm kp write-longread stop-slop stephen-king ~/.agents/skills/
```

Для Claude Code:

```bash
mkdir -p ~/.claude/skills
cp -R quiz offer hormozi equalizer design-swarm kp write-longread stop-slop stephen-king ~/.claude/skills/
```

Вместо глобальной установки в Claude Code можно скопировать те же папки в `.claude/skills/`
вашего проекта. Откройте новую сессию после установки. Если хост не обнаружил навык,
попросите его явно прочитать нужный `SKILL.md` из склонированного репозитория.

## Первый запуск

В Claude Code используйте `/quiz`, в Codex — `$quiz` или явно назовите навык.
Аргументы и обычный текст запроса одинаковы:

```text
$offer --magnet Придумай лид-магнит для моего продукта.
Аудитория: ... Продукт: ... Следующее платное действие: ...
Что уже подтверждено: ... Собери весь вариант с явными допущениями.
```

```text
$quiz Создай полный глубокий продающий квиз для моего продукта:
вопросы, адаптивные ветки, персональные результаты, объяснение продукта,
оффер и аналитика. Аудитория: ... Продукт: ... Условия: ...
Не останавливайся только на заголовках.
```

```text
$hormozi --review Проверь этот оффер: ...
$equalizer Проверь текст под эту аудиторию: ...
$design-swarm Собери интерфейс по утверждённой архитектуре квиза: ...
$kp Собери КП по этому брифу: ...
$write-longread Напиши продающую статью для этого продукта: ...
$stop-slop Отредактируй текст, сохрани факты и авторский голос: ...
$stephen-king Сократи и усили этот текст: ...
```

Сначала дайте фактуру продукта и аудитории. Если она уже есть — исследование можно пропустить.
Рабочая цепочка: `hormozi --mine → offer → hormozi --review / equalizer → quiz → design-swarm`.
КП и лонгрид — отдельные выходы из того же оффера; редакторы подключаются к готовому тексту.
Нет необходимости запускать все девять скиллов на каждый запрос.

## Возможности и границы

Для текстовых этапов достаточно AI-ассистента. Для свежего исследования нужен веб-доступ
или предоставленные источники. Для файлов и интерфейса — соответствующие инструменты хоста.
MCP, внешние сервисы и другие скиллы не нужны для базового прохода. Если параллельные
агенты недоступны, возможна последовательная работа; она не заменяет независимый ревью.

Критические непроверенные факты остаются блокерами запуска. Скиллы не выдумывают отзывы,
кейсы, ценники, срочность и гарантии. Редакторские оценки не прогнозируют конверсию.
Медицинские и другие чувствительные утверждения требуют профильной проверки.
Реальную конверсию, длительность прохождения и удобство проверяют на прототипе и трафике.

Проверить структуру комплекта локально: `python3 tools/check_bundle.py`.

## Использование

Можно использовать и адаптировать инструкции в своих проектах. Упоминания авторов
маркетинговых методик — атрибуция идей; комплект не является их официальным продуктом
и не включает полные тексты книг.
