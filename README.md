# Quiz & Offer Skills для Claude Code

Три скилла для Claude Code, которые собирают **квиз-воронки** и **офферы, от которых невозможно отказаться**. Методология — синтез Хормози, Шварца, Хэлберта, Хопкинса и практики продающих квизов.

## Что внутри

| Скилл | Команда | Что делает |
|-------|---------|-----------|
| **quiz** | `/quiz` | Проектирует персонализированные квизы пяти типов: исследование, квалификация, onboarding, короткая и глубокая продажа. Глубокий режим строит адаптивный путь от вопросов и мини-результата до механизма, продукта и оффера. |
| **offer** | `/offer` | Конструктор оффера в режиме штурма: приносит 3–5 вариантов на каждом шаге (обещание → формат → механика → бонусы → risk reversal → цена → имя), ты выбираешь, скилл докручивает. На выходе — Core Offer / Tripwire / Lead Magnet. |
| **hormozi** | `/hormozi` | Offer Architect по «$100M Offers»: создание оффера (`--build`), суровый scoring-ревью (`--review`), разведка рынка и voice-of-customer (`--mine`). Value Equation, уникальный механизм, стек бонусов, гарантии. |

Все три скилла используют `references/` для подробных методик. `/quiz` хранит там контракт
глубокого адаптивного квиза: персонализацию, ветвление, privacy и agency, evidence и аналитику.

## Как установить

Скопируй папки скиллов в директорию скиллов Claude Code:

```bash
# глобально (доступно во всех проектах)
cp -R quiz offer hormozi ~/.claude/skills/

# или только в текущий проект
mkdir -p .claude/skills && cp -R quiz offer hormozi .claude/skills/
```

Перезапусти Claude Code — скиллы подхватятся.

## Как пользоваться

В Claude Code просто вызови команду:

```
/quiz          собрать персонализированный квиз или квиз-воронку
/offer         собрать оффер штурмом (Core / Tripwire / Lead Magnet)
/hormozi       создать/проверить оффер или сделать разведку рынка
/hormozi --review   суровый scoring существующего оффера
/hormozi --mine     разведка рынка + язык аватара
```

Скиллы поднимают доступную фактуру о продукте и аудитории, уточняют только критичные пробелы и
собирают результат под задачу. Полный запрос на глубокий квиз не останавливается на выборе
хука: он сразу даёт архитектуру экран за экраном и отмечает неизвестные данные как блокеры.

## Как устроен глубокий квиз

`/quiz` не копирует чужую последовательность экранов. Он подбирает функции под человека,
продукт, температуру трафика и риск действия. Рабочая форма обычно выглядит так:

```text
6–10 тематических вопросов → первый мини-результат → уточнение → персональная обратная связь
→ надежда → механизм → доказательства → презентация продукта → маршрут → оффер или выход
```

Количество экранов не фиксировано. Готовая ветка идёт коротким путём, сомневающаяся получает
нужное объяснение, а нерелевантная — честный результат без продажи.

## Как они сочетаются

```
/hormozi --mine   →  разведка рынка, язык аудитории, gap-map
        ↓
/offer            →  собрать оффер штурмом на этой фактуре
        ↓
/hormozi --review →  стресс-тест оффера по Value Equation
        ↓
/quiz             →  упаковать в квиз-воронку с этим оффером
```
