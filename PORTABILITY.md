# Переносимость комплекта

## Что включено

- `quiz`, `offer`, `hormozi` — исходное ядро репозитория, очищенное от офисных привязок.
- `design-swarm` — полный процесс смыслов и дизайна с двумя локальными справочниками.
- `equalizer` — самостоятельный смысловой ревьюер с критериями, структурами, примерами и ограничениями.
- `kp` — реальная методика подготовки КП и расчёта ROI вместо ссылки-обёртки на частный офис.
- `write-longread` — полный процесс и справочники вместо ссылки-обёртки.
- `stop-slop` — совместимое имя для действующего метода редакторского фильтра anti-slop.
- `stephen-king` — редактура прозы, на которую ссылается методика офферов.

## Что изменено для публикации

Убраны личные/клиентские сведения, внутренние имена и адреса, пути к офису, память агентов,
обязательные журналы, частные скрипты и скрытые роли. Исходные установленные скиллы автора
не меняются. Примеры здесь учебные и не служат доказательствами для чужого продукта.

Внешние команды и MCP заменены возможностями хоста или явно необязательны. Не требуется
устанавливать остальные скиллы AI-офиса. Если этап требует недоступного инструмента,
ассистент называет ограничение; отсутствие источника не компенсирует выдуманной фактурой.

## Зависимости и вызовы

| Скилл | Связанные скиллы комплекта |
|---|---|
| quiz | offer, equalizer, design-swarm |
| offer | hormozi, equalizer; выходы в quiz, kp, write-longread |
| hormozi | equalizer, write-longread, stop-slop, stephen-king |
| design-swarm | quiz, offer, equalizer при соответствующем задании |
| equalizer | Может проверять любой текст самостоятельно |
| kp, write-longread | Используют фактуру оффера; могут стартовать с брифа |
| stop-slop, stephen-king | Самостоятельная редактура переданного текста |

Соседние навыки хост может вызвать командой, через каталог навыков или чтение их
`SKILL.md`. Пакет не предполагает единый API субагентов. Проектные источники и согласования
пользователь передаёт сам; частные каталоги автоматически не читаются.

## Проверки

`tools/check_bundle.py` проверяет состав, имена, локальные ссылки и запрещённые офисные
привязки, а также копирование в чистый каталог. Он не меняет проверяемые файлы.
Свежие поведенческие пробы и независимое ревью перед публикацией не равны гарантии
автозагрузки в любой версии Codex/Claude Code или коммерческой эффективности.
