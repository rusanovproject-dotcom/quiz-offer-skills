# Message Mining — Руководство по разведке рынка

Полный протокол сбора рыночной разведки перед созданием оффера.
Источник: Stefan Georgi (RMBC), Claude Hopkins, Gary Halbert, Eugene Schwartz.

---

## Зачем это делать

Копирайтеры-любители придумывают язык из головы.
Мастера берут язык у самой аудитории.

Задача Message Mining — найти слова, которые уже крутятся в голове у аватара.
Когда оффер написан его словами — он не воспринимается как реклама. Он воспринимается как «это про меня».

> «Войди в разговор, который уже ведётся в голове у покупателя.» — Robert Collier

## Этап 1: Разведка конкурентов

### Шаблон: 5 конкурентов × 7 параметров

| Параметр | Конкурент 1 | Конкурент 2 | Конкурент 3 | Конкурент 4 | Конкурент 5 |
|----------|------------|------------|------------|------------|------------|
| **Название / URL** | | | | | |
| **Главный оффер** (1 строка) | | | | | |
| **Заголовок лендинга** (дословно) | | | | | |
| **Главное обещание** | | | | | |
| **Гарантия** | | | | | |
| **Цена / модель** | | | | | |
| **Главная слабость** (что они НЕ говорят / что не закрывают) | | | | | |

### Где искать конкурентов

- Google: `[ниша] + курс / программа / coaching`
- YouTube: топ-видео по ключевым запросам ниши — кто рекламируется
- Facebook Ads Library: `facebook.com/ads/library` → ищи по ключевым словам
- Telegram/Instagram: поиск по хэштегам и ключевым словам
- Tilda/Вордпресс лендинги по ключевым запросам

### Что фиксировать дословно

- Заголовки (H1, H2) — это их главные обещания
- CTA кнопки — формулировки призыва к действию
- Буллеты выгод — что они считают своим главным преимуществом
- Гарантии — как формулируют снятие риска
- Социальные доказательства — какие форматы, какие цифры называют

## Этап 2: Голос клиента (Voice of Customer)

### Источники — где копать и что искать

**1. Amazon отзывы на книги в нише**
- Ищи 1-3 звезды: что разочаровало, что ожидали и не получили
- Ищи 5 звезд: что изменилось после прочтения, конкретные результаты
- Копируй дословные фразы — это готовые заголовки

**2. Reddit / Quora / Форумы**
- Ищи: `[проблема] reddit` или `[ниша] quora`
- Что ищут: ветки с вопросами о проблеме, советами, провалами
- Что копировать: первые предложения постов — там неотфильтрованная боль

**3. Telegram-группы и чаты**
- Найди 3-5 тематических групп
- Поиск по ключевым словам проблемы
- Фиксируй: на что жалуются, что спрашивают, что советуют друг другу

**4. YouTube комментарии**
- Топ-видео конкурентов по ключевому запросу → раздел комментариев
- Ищи: вопросы, разочарования, «а что если...», «а как насчёт...»
- Фразы типа «я пробовал X, но...» — золото для механизма

**5. Facebook Groups**
- Тематические группы по нише
- Поиск по ключевым болям
- Пины и посты с наибольшим числом комментариев

**6. Интервью с 5-10 реальными клиентами (или потенциальными)**
Вопросы для интервью:
```
1. До того как нашли решение — что вы пробовали?
2. Почему это не сработало?
3. Что для вас было главным страхом при выборе?
4. Как выглядел ваш обычный день, когда проблема была в полную силу?
5. Как вы поняли, что хотите изменить это?
6. Какой результат вы считали бы победой?
```

## Этап 3: Gap Map — таблица разрыва

Gap Map — это инструмент поиска дыры на рынке.
Цель: найти что говорят ВСЕ (это стало банальностью) и что НЕ ГОВОРИТ НИКТО (это возможность).

### Шаблон Gap Map

| Что говорят ВСЕ конкуренты (банальность) | Что НЕ ГОВОРИТ НИКТО (дыра = возможность) |
|------------------------------------------|-------------------------------------------|
| «Больше клиентов» | «Правильные клиенты, которые не уходят» |
| «Масштабируйся быстро» | «Выстрой систему, которая работает без тебя» |
| «Научим продавать» | «Сделаем так, чтобы клиенты приходили сами» |
| «Проверенная методология» | «Система из первых принципов под твой рынок» |
| «Индивидуальный подход» | Никто не объясняет ЧТО именно индивидуально |

### Как заполнять Gap Map

1. Собери все заголовки и обещания конкурентов из таблицы выше
2. Найди повторяющиеся паттерны — это «банальности рынка»
3. Задай вопрос: «Что аватар хочет услышать, чего ещё никто не говорит?»
4. Задай вопрос: «Что аватар боится, о чём никто не говорит прямо?»
5. Дыра = пересечение «хочет услышать» и «никто не говорит»

## Этап 4: Диагностика рынка по Schwartz

Перед тем как идти дальше — обязательно поставь два диагноза.

### Диагноз 1: Awareness Level аудитории

| Уровень | Что знает аватар | Трафик | Точка входа оффера |
|---------|-----------------|--------|-------------------|
| 1 — Unaware | Не знает о проблеме | Холодный FB/YouTube | История, паттерн идентификации |
| 2 — Problem Aware | Знает боль, не знает решений | Поисковый трафик по симптомам | Назови боль острее, чем они сами |
| 3 — Solution Aware | Знает, что решение есть | Поиск по «как сделать X» | Покажи категорию, уникальный механизм |
| 4 — Product Aware | Знает тебя, не уверен | Ретаргет, e-mail база | Дифференцируй, снимай сомнения |
| 5 — Most Aware | Готов купить | Горячая база, запросы цен | Цена + причина действовать сейчас |

**Как определить уровень:**
- Откуда идёт трафик? Холодный → 1-2, ретаргет → 3-4, база → 4-5
- Что они ищут? Симптомы → 2, решения → 3, бренды → 4

### Диагноз 2: Market Sophistication (стадия рынка)

| Стадия | Ситуация | Стратегия |
|--------|----------|-----------|
| 1 — Прямое утверждение | Рынок новый, первый игрок | Просто назови результат: «Похудей за 30 дней» |
| 2 — Увеличение | Конкуренты скопировали | Кричи громче: «за 10 дней», «гарантированно» |
| 3 — Механизм | Гонка обещаний надоела | Переключись с ЧТО на КАК: уникальный механизм |
| 4 — Расширение механизма | Механизмы скопированы | Усложни/уточни механизм, добавь имя системе |
| 5 — Идентификация | Всё скопировано | Переключись на принадлежность: «для [узкий аватар]» |

**Как определить стадию:**
- < 5 конкурентов → Стадия 1-2
- 5-20 конкурентов → Стадия 2-3
- > 20 конкурентов, все говорят одно → Стадия 4-5
- Если все кричат одно — ты должен говорить другое

## Этап 5: Сборка языка оффера из сырых данных

### Как превратить разведку в оффер

**Шаг 1: Выпиши все дословные фразы аватара**
Из отзывов, комментариев, интервью — собери 20-30 дословных цитат.
Ищи эмоциональные формулировки, конкретные боли, мечты.

**Шаг 2: Найди повторяющиеся паттерны**
Какие слова встречаются чаще всего?
Какие боли называются одинаково разными людьми?
Это и есть язык оффера.

**Шаг 3: Найди фразы провала («почему не сработало»)**
«Я пробовал X, но...» — это точка входа для уникального механизма.
Твой механизм объясняет, почему X не работает и как ты делаешь иначе.

**Шаг 4: Составь заготовки для оффера**

```
Аватар: [кто конкретно, из разведки]
Боль (их словами): [дословно из отзывов/комментариев]
Мечта (их словами): [дословно]
Что пробовали: [список]
Почему провалилось: [причины — это точка для механизма]
Что НЕ говорят конкуренты: [из Gap Map]
```

## Реальные примеры Gap'ов

### Ниша: онлайн-образование (маркетинг для бизнеса)

| Что говорят все | Дыра |
|----------------|------|
| «Научим продавать в соцсетях» | «Система, которая продаёт даже когда ты не пишешь посты» |
| «100500 инструментов маркетинга» | «3 рычага, которые дают 80% результата» |
| «Команда экспертов с опытом» | «Один человек, который сделал именно то, что тебе нужно» |

### Ниша: AI-автоматизация для бизнеса

| Что говорят все | Дыра |
|----------------|------|
| «Внедрим AI в ваши процессы» | «AI-система, которой не нужно управлять каждый день» |
| «Сэкономим время на рутине» | «Освободим 15 часов в неделю на работу Tier 1» |
| «ChatGPT для бизнеса» | «настройка учёта заявок под процессы команды» |

### Ниша: коучинг по продажам

| Что говорят все | Дыра |
|----------------|------|
| «Закрывай больше сделок» | «Строй систему где клиенты сами закрывают себя» |
| «Скрипты продаж» | «Понимание психологии — скрипты не нужны» |
| «Наши клиенты зарабатывают X» | «Один кейс детально: до/после, что именно изменилось» |
